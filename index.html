Simulators & offline IDEs

Learn by doing, right inside the app

Eight interactive labs that turn theory from the textbook into something you can run, see and test.

Offline C compiler IDE

Syntax highlighting, line numbers, undo and redo, auto-indent, error markers, compiler hints and an interactive scanf/printf console.

C algorithm simulator

Step through your program line by line with custom inputs and watch variables change in real time.

HTML / CSS / JS playground

A multi-tab web IDE with live preview, a mobile and desktop viewport switcher, and console hints.

Logic gate simulator

AND, OR, NOT, NAND, NOR, XOR and XNOR with real-time truth tables.

Number system converter

Convert between binary, octal, decimal and hexadecimal, fractions included, with step-by-step solutions.

Network topology simulator

Bus, star, ring, mesh, tree and hybrid topologies with animated packets and broken-cable fault simulation.

SQL & DBMS practice lab

Run relational queries offline and practise SELECT, INSERT, UPDATE, DELETE and JOIN.

Practice & exam suite

Chapter-wise board-aligned MCQs, timed model tests, flashcards and detailed score analytics.

FAQ

Frequently asked questions

Does ICT Assistant need the internet?

No. After installation, all chapters, simulators, IDEs and mock exams work fully offline.

Which Android versions are supported?

Android 7.0 and above (API 24 to 36).

Which APK should I download?

Most modern phones should use the arm64-v8a build, which is the smallest. Older 32-bit devices need armeabi-v7a, and the universal APK works on any supported device.

Is the syllabus aligned with the HSC board?

Yes. Chapters 1–6 are organised to follow the official HSC ICT board syllabus, and the practice MCQs are board-aligned.

Which languages does the app support?

Both Bangla and English.

Is the app open source?

No. ICT Assistant is closed-source, proprietary software. Redistribution, decompilation and unauthorised modification are prohibited.
